## 与运行时资源的关系

母版不直接对外提供，运行时资源由母版复制后派生：

```
assets/avatar/*.png                     ← 母版（本目录）
        │
        ├─→ src/maimai_watchdog/static/img/cards/            方图副本（页面卡面原图）
        │
        └─→ src/maimai_watchdog/static/img/cards/portrait/   竖图副本（全身立绘）
                    │
                    └─→ scripts/make_web_variants.py 派生 avatar/face/ring/zoom 四套 WebP
```

两条链路分工明确：`assets/` 保留可再加工的原始画质，`src/.../static/` 只放浏览器实际加载的体积/格式优化版本。
改图时改母版，再跑 `scripts/make_web_variants.py` 重新派生，不要在 `static/` 里直接改。

> `static/` 下的两份 PNG 副本与本目录母版**逐字节一致**（直接复制，未重新编码压缩），
> 目的是让母版与运行时资源各归其位、互不依赖。因此这 8 个文件在仓库中会出现两次，属有意为之。

## 素材合规状态

四张形象图均为**原创角色**（参赛者自主使用 AI 工具优化生成），非第三方素材改编：

- 汉堡、薯条为**通用食物图形**
- **不含**任何品牌标识：金色拱门、麦当劳名称、「Mc」前缀、叔叔形象
- 薯条纸盒为**无标识空白款**
- 未与第三方品牌元素并置
- 符合活动内容合规 e）款「不得将麦当劳品牌与其他品牌对比」——本素材仅作单一品牌场景使用
